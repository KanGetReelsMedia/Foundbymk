# Gethsemane Garden PWA

Christian Lifestyle Church App - Kankakee
Features: Daily Word, Jesus Speaks (Red Letters), Share (no login), Journal + PDF, Connect

## Deploy to GitHub Pages

1. Create new repo: gethsemane-garden or gardenchurchkankakee
2. Upload all files in this folder to main branch (keep folder structure)
3. Go to Settings > Pages
   - Source: Deploy from a branch
   - Branch: main / root
   - Save
4. Live at: https://YOURUSERNAME.github.io/gethsemane-garden/

## PWA Install
- iPhone: Open in Safari > Share > Add to Home Screen
- Android: Chrome > Install banner
